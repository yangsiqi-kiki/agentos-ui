## 概述

页头展示带标题、元信息与辅助操作的页面头部，用于列表 / 详情等页面顶栏。

## 示例

### 默认
完整页头：标题、描述与操作区。
<Canvas of={PageHeaderStories.Default} />

### 单选切换
页头内嵌单选，用于视图模式切换。
<Canvas of={PageHeaderStories.SingleSelect} />

### 极简
仅保留标题的精简页头。
<Canvas of={PageHeaderStories.Minimal} />

## 用法

```tsx
import { PageHeader } from '@agentos/design-system'

<PageHeader title="知识库" />
```
