## 这是什么

`@agentos/design-system` 是 AgentOS 产品的设计系统包，统一：

- **Design Tokens**：颜色、字体、圆角、间距等语义变量（`--agentos-*`）
- **React 组件**：按原子设计分层实现的可复用 UI
- **Tailwind Preset**：宿主应用可直接接入的主题扩展

本 Storybook 即该设计系统的在线说明书，面向设计师、产品与前端开发共同阅读。

组件实现禁止硬编码色值，一律使用语义 token，以便后续接入暗色模式时无需改组件代码。

## 包结构

```
packages/@agentos/design-system
├── DESIGN.md                 # 对外设计契约（Figma ↔ CSS ↔ Tailwind）
├── docs/token-reference.md   # 完整 token 附录
├── src/
│   ├── tokens/               # 源 JSON、生成 CSS / theme
│   ├── components/

│   │   ├── molecules/
│   │   ├── organisms/
│   │   ├── layouts/
│   │   └── pages/
│   └── index.ts              # 公共导出
└── storybook/                # 本说明书
```
