## 概述

标签输入框以可移除标签的形式输入多个值，适合关键词、收件人等场景。

## 示例

### 默认
空标签输入，回车或确认后生成标签。
<Canvas of={InputTagStories.Default} />

### 填充态
已有多个标签时的视觉密度。
<Canvas of={InputTagStories.Filled} />

### 自定义标签
自定义标签渲染或初始值组合。
<Canvas of={InputTagStories.CustomTags} />

### 禁用
不可增删标签的只读态。
<Canvas of={InputTagStories.Disabled} />

## 用法

```tsx
import { InputTag } from '@agentos/design-system'

<InputTag defaultValue={['design', 'system']} placeholder="添加标签" />
```
