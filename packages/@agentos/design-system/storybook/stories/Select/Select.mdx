## 概述

选择器从下拉列表中选择一个或多个选项，支持尺寸、填充态与禁用。

## 示例

### 默认
单选下拉的基础形态。
<Canvas of={SelectStories.Default} />

### 填充态
已选中值时的填充外观。
<Canvas of={SelectStories.Filled} />

### 多选
一次选择多个选项并以标签展示。
<Canvas of={SelectStories.Multiple} />

### 全部尺寸
对比不同高度的选择器。
<Canvas of={SelectStories.AllSizes} />

### 禁用
不可展开的禁用态。
<Canvas of={SelectStories.Disabled} />

## 用法

```tsx
import { Select } from '@agentos/design-system'

<Select
  placeholder="请选择"
  options={[
    { label: '选项 A', value: 'a' },
    { label: '选项 B', value: 'b' },
  ]}
/>
```
