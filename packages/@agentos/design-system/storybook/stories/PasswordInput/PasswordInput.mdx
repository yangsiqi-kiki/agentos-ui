## 概述

密码输入框用于输入密码，支持显示 / 隐藏切换，状态与尺寸体系与 Input 对齐。

## 示例

### 默认
空值密码输入，右侧可切换明文显示。
<Canvas of={PasswordInputStories.Default} />

### 有值
已填入密码时的外观与显隐交互。
<Canvas of={PasswordInputStories.WithValue} />

### 危险状态
校验失败时的 danger 边框与提示色。
<Canvas of={PasswordInputStories.Danger} />

### 全部尺寸
对比不同高度下的密码输入框。
<Canvas of={PasswordInputStories.AllSizes} />

## 用法

```tsx
import { PasswordInput } from '@agentos/design-system'

<PasswordInput placeholder="请输入密码" />
```
