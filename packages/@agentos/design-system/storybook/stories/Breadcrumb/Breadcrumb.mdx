## 概述

面包屑展示当前页面在层级结构中的位置，便于返回上级；支持折叠与多种分隔符。

## 示例

### 默认
两级路径的基础面包屑。
<Canvas of={BreadcrumbStories.Default} />

### 三级路径
更深层级的导航路径展示。
<Canvas of={BreadcrumbStories.ThreeLevels} />

### 折叠
路径过长时中间层级折叠为省略号。
<Canvas of={BreadcrumbStories.Collapsed} />

### 全部分隔符
对比斜杠、箭头等不同分隔符样式。
<Canvas of={BreadcrumbStories.AllSeparators} />

## 用法

```tsx
import { Breadcrumb } from '@agentos/design-system'

<Breadcrumb
  items={[
    { label: '首页', href: '/' },
    { label: '设置' },
  ]}
/>
```
