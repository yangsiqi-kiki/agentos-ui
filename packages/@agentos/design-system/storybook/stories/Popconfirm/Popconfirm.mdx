## 概述

由 Popover 衍生的确认气泡，用于删除等需二次确认的轻量操作。默认展示警告图标、标题、描述与取消/确认按钮，支持 12 种弹出位置。

## 用法

```tsx
import { Popconfirm, Button } from '@agentos/design-system'

<Popconfirm
  title="Confirm"
  description="Are you sure you want to delete?"
  onConfirm={() => {}}
>
  <Button theme="danger" appearance="outline">Delete</Button>
</Popconfirm>
```
