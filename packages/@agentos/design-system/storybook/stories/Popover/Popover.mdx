## 概述

悬浮气泡，用于展示补充信息或轻量操作。支持标题/无标题、信息/操作两类内容，以及 12 种弹出位置与箭头。

## 示例

### 默认
带标题与描述的信息气泡。

### 无标题
仅描述的轻量信息气泡。

## 用法

```tsx
import { SimplePopover, Button } from '@agentos/design-system'

<SimplePopover
  title="Popover title"
  description="This is a lightweight container for supplementary information."
  placement="top"
  trigger={<Button>Open</Button>}
/>
```
