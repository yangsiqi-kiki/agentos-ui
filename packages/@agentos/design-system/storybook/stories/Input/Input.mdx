## 概述

输入框用于输入和编辑短文本，支持前后缀、尺寸与校验状态（danger / warning / success）。

## 示例

### 默认
基础单行文本输入。
<Canvas of={InputStories.Default} />

### 前后缀
在输入区两侧放置图标或附加文案。
<Canvas of={InputStories.WithPrefixAndSuffix} />

### 全部尺寸
对比 sm / default / lg 三种高度。
<Canvas of={InputStories.AllSizes} />

### 全部状态
展示 danger / warning / success 等校验反馈。
<Canvas of={InputStories.AllStatuses} />
