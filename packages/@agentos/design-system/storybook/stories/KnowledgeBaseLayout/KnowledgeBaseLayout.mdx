## 概述

知识库布局是知识库相关页面的共享外壳：全局顶栏、左侧 CUI 侧栏、工作区标签栏与面包屑行。面包屑下方通过 `children` 替换页面主体内容。

## 用法

```tsx
import { KnowledgeBaseLayout } from '@agentos/design-system'

<KnowledgeBaseLayout
  breadcrumbItems={[
    { label: 'Knowledge base' },
    { label: 'All knowledge bases' },
  ]}
>
  <div>Page body</div>
</KnowledgeBaseLayout>
```
