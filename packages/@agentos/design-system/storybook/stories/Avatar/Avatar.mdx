## 概述

头像以紧凑视觉形式展示用户、团队或实体身份，支持圆形 / 方形与多种尺寸。

## 示例

### 默认
圆形头像与文字回退。
<Canvas of={AvatarStories.Default} />

### 方形
方形裁切，适合品牌或非人物标识。
<Canvas of={AvatarStories.Square} />

### 全部尺寸
对比各尺寸头像的视觉层级。
<Canvas of={AvatarStories.AllSizes} />

### 图片
使用真实图片作为头像源。
<Canvas of={AvatarStories.WithImage} />

## 用法

```tsx
import { Avatar } from '@agentos/design-system'

<Avatar fallback="AB" size="md" />
```
