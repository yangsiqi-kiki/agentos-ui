## 概述

复选框用于选择一项或多项独立选项，支持半选与分组布局。

## 示例

### 默认
未选中的基础复选框。
<Canvas of={CheckboxStories.Default} />

### 已选中
选中态的勾选外观。
<Canvas of={CheckboxStories.Checked} />

### 半选
父级部分子项选中时的 indeterminate 态。
<Canvas of={CheckboxStories.Indeterminate} />

### 水平分组
多个选项横向排列。
<Canvas of={CheckboxStories.Group} />

### 垂直分组
多个选项纵向排列。
<Canvas of={CheckboxStories.VerticalGroup} />

## 用法

```tsx
import { Checkbox } from '@agentos/design-system'

<Checkbox defaultChecked>同意协议</Checkbox>
```
