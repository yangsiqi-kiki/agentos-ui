## 概述

分割线以轻量视觉边界分隔内容区域，支持水平 / 垂直、虚线与中间文案。

## 示例

### 默认
水平实线分割。
<Canvas of={DividerStories.Default} />

### 带文案
分割线中间插入说明文字。
<Canvas of={DividerStories.WithLabel} />

### 虚线
虚线样式，分隔感更弱。
<Canvas of={DividerStories.Dashed} />

### 垂直
用于行内元素之间的竖向分隔。
<Canvas of={DividerStories.Vertical} />

## 用法

```tsx
import { Divider } from '@agentos/design-system'

<Divider />
<Divider label="或者" />
```
