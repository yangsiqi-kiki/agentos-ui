## 概述

按钮用于触发操作或导航，覆盖主次交互场景。通过 `theme`（primary / secondary / black / danger）与 `appearance`（solid / outline / ghost）组合表达语义强度；`shape` 支持直角圆角（rectangle）与胶囊全圆（rounded）。

## 用法

```tsx
import { Button } from '@agentos/design-system'

<Button theme="primary" appearance="solid" size="default">
  Confirm
</Button>

<Button theme="primary" appearance="solid" shape="rounded" leadingIcon={<Star />}>
  Confirm
</Button>
```
