## 这是什么

`component-creator` 是给 Cursor Agent 使用的技能说明（Skill）。Agent 读取后会：

1. 探测项目形态（React / Next.js、Tailwind、shadcn、Storybook、`DESIGN.md`）
2. 缺依赖时安装并初始化 UI 基建
3. 按 `DESIGN.md`（若存在）映射 token，生成 shadcn 风格组件
4. 仅当检测到 Storybook 时写入 story

完整正文见下方，可一键复制到你的仓库。
