## 概述

滑动输入条通过拖动连续区间调整数值，可附带数字输入与两端图标。

## 示例

### 默认
带数值输入联动的滑动条。
<Canvas of={SliderStories.Default} />

### 无输入框
仅保留滑轨与滑块，适合空间紧凑场景。
<Canvas of={SliderStories.WithoutInput} />

### 带图标
滑轨两端放置语义图标。
<Canvas of={SliderStories.WithIcons} />

### 禁用
不可拖动的只读数值展示。
<Canvas of={SliderStories.Disabled} />

## 用法

```tsx
import { Slider } from '@agentos/design-system'

<Slider defaultValue={[50]} min={0} max={100} />
```
