## 概述

下拉菜单，用于触发器旁展示一组操作或选项。菜单项视觉对齐 Figma Dropdown menu-item；其余结构沿用 shadcn DropdownMenu（Radix）API。

## 用法

```tsx
import {
  Button,
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from '@agentos/design-system'

<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <Button>Open</Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuItem>Beijing</DropdownMenuItem>
    <DropdownMenuItem>Shanghai</DropdownMenuItem>
  </DropdownMenuContent>
</DropdownMenu>
```
