## 概述

标签页在同一容器下组织可切换的相关视图，支持线形、卡片、圆角与纵向布局。

## 示例

### 默认
线形标签页的基础切换。
<Canvas of={TabsStories.Default} />

### 图标与计数
标签上附带图标或数量徽标。
<Canvas of={TabsStories.WithIconAndCount} />

### 卡片
卡片形态标签，边界更明显。
<Canvas of={TabsStories.Card} />

### 卡片间距
卡片标签带间距（gutter）的排列。

### 纵向
标签纵向排列，适合侧栏导航。

### 全部尺寸
对比不同尺寸标签页。
<Canvas of={TabsStories.AllSizes} />

## 用法

```tsx
import { Tabs, TabsList, TabsTrigger, TabsContent } from '@agentos/design-system'

<Tabs defaultValue="a">
  <TabsList>
    <TabsTrigger value="a">标签 A</TabsTrigger>
    <TabsTrigger value="b">标签 B</TabsTrigger>
  </TabsList>
  <TabsContent value="a">内容 A</TabsContent>
  <TabsContent value="b">内容 B</TabsContent>
</Tabs>
```
