## 概述

数字输入框用于输入、步进与校验数值，支持按钮步进模式与前后缀。

## 示例

### 默认
带步进控制的基础数字输入。
<Canvas of={InputNumberStories.Default} />

### 按钮模式
使用显式加减按钮调整数值。
<Canvas of={InputNumberStories.ButtonMode} />

### 无前后缀
去掉 affix，仅保留数字输入本体。
<Canvas of={InputNumberStories.WithoutAffixes} />

### 禁用
不可编辑的数值展示态。
<Canvas of={InputNumberStories.Disabled} />

## 用法

```tsx
import { InputNumber } from '@agentos/design-system'

<InputNumber defaultValue={1} min={0} max={100} />
```
